## 4. Туршилтын хэрэгжилт

### 4.1 Section A — Happy-path тестүүд

Эхний шатанд програмын үндсэн зөв ажиллагааг шалгах 5 тест боловсруулав.

- `testLetterGradeA()` — A үнэлгээ буцаах эсэх.
- `testLetterGradeB()` — B үнэлгээ буцаах эсэх.
- `testLetterGradeC()` — C үнэлгээ буцаах эсэх.
- `testGpaAverage()` — олон дүнгийн голч зөв тооцох эсэх.
- `testFullScholarship()` — бүрэн тэтгэлэг зөв олгох эсэх.

Үр дүн: 5 тест бүгд амжилттай ажилласан.

| Хэмжүүр | Үр дүн |
|---|---:|
| Line coverage | 60% |
| Branch coverage | 46.34% |

Эхний шатанд зарим кодын мөр болон нөхцөлт салааллууд шалгагдаагүй байв. JaCoCo тайланд шар өнгө нь хэсэгчлэн хамрагдсан, улаан өнгө нь огт хамрагдаагүй кодыг илэрхийлнэ.

**Нотолгоо:** `results/mvn-verify-A.txt`, `results/jacoco-A.csv`

### 4.2 Section B — Branch болон line coverage

Дараагийн шатанд нөхцөл бүрийн үнэн болон худал үр дүнг шалгах нэмэлт тестүүд боловсруулав.

Үүнд:

- `letterGrade()` аргын F үнэлгээ болон буруу оролтын шалгалтууд.
- `gpa()` аргын switch-ийн default салаа.
- GPA, кредитийн босго болон сахилгын зөрчлийн нөхцөлүүд.
- `scholarship()` аргын буруу GPA болон кредитийн оролтын шалгалтууд.
- GPA тооцооллын A, B, C, D, F үнэлгээний салаанууд.

Мөн `gpa < 0 || gpa > 4 || credits < 0` нөхцөлийн гурван тусдаа үнэн үр дүнг тус бүрээр нь шалгав. `&&` оператортой нөхцөлүүдийн үнэн болон худал үр дүнг хамруулах нэмэлт тестүүдийг боловсруулав.

Үр дүн: 22 тест бүгд амжилттай ажиллаж, line болон branch coverage хоёулаа 100%-д хүрсэн.

| Хэмжүүр | Хамрагдсан | Алдсан |
|---|---:|---:|
| Instructions | 149 | 0 |
| Branches | 41 | 0 |
| Lines | 25 | 0 |

**Нотолгоо:** `results/mvn-verify-B.txt`, `results/jacoco-B.csv`

### 4.3 Section C — GPA давталтын хилийн тестүүд

`gpa()` арга нь массив дахь дүнг давталтаар боловсруулдаг тул дараах тохиолдлуудыг шалгав.

- `null` массив өгөхөд `IllegalArgumentException` үүсэх.
- Хоосон массив өгөхөд `IllegalArgumentException` үүсэх.
- Нэг элементтэй массивын голч зөв тооцогдох.
- Олон элементтэй массивын голч зөв тооцогдох.

Нэг болон олон элементтэй массивын тестүүдийг нэмж, нийт тестийн тоог 24 болгосон.

Эдгээр тест нь давталтын өөр өөр хэмжээтэй оролтыг шалгаж, бодит хэрэглээнд гарч болох хилийн тохиолдлуудыг баталгаажуулсан. Coverage-ийн үзүүлэлт өөрчлөгдөөгүй ч давталтын ажиллагааны зөв байдлыг илүү өргөн хүрээнд шалгах боломж бүрдсэн.

Үр дүн: 24 тест бүгд амжилттай ажиллаж, line болон branch coverage 100% хэвээр үлдсэн.

**Нотолгоо:** `results/mvn-verify-C.txt`, `results/jacoco-C.csv`

### 4.4 Section D — Boundary Value Testing

Энэ шатанд `letterGrade()` аргын үнэлгээний зааг утгуудыг шалгах 7 тест нэмэв.

| Оролтын оноо | Хүлээгдэж буй үнэлгээ |
|---:|---|
| 60 | D |
| 59.99 | F |
| 69.99 | D |
| 0 | F |
| 100 | A |
| 89.99 | B |
| 90 | A |

Эхний туршилтын гүйлтээр `testLetterGradeAt60()` тест амжилтгүй болсон.

```text
Tests run: 31, Failures: 1, Errors: 0, Skipped: 0

expected: <D> but was: <F>
BUILD FAILURE
```

Алдааны шалтгаан нь эх код дахь дараах нөхцөл байв.

```java
if (score > 60) return "D";
```

60 оноо нь D үнэлгээний доод хязгаарт багтах ёстой боловч `>` оператороос шалтгаалан F үнэлгээ буцааж байв.

Иймээс нөхцөлийг дараах байдлаар засварлав.

```java
if (score >= 60) return "D";
```

Засварын дараа бүх 31 тест амжилттай ажиллаж, Maven-ийн `BUILD SUCCESS` үр дүн гарсан.

**Нотолгоо:**
- `results/mvn-test-D-fail.txt`
- `results/mvn-verify-final.txt`
- `results/jacoco-final.csv`

## 5. Control Flow Graph (CFG)

`ScholarshipCalculator` классын `scholarship()` аргын удирдлагын урсгалыг харуулахын тулд Control Flow Graph боловсруулав.

CFG диаграмд дараах хэсгүүдийг дүрслэв:

- Эхлэх болон дуусах цэг.
- Буруу оролтыг шалгах нөхцөлүүд.
- Сахилгын зөрчлийн шалгалт.
- GPA болон кредитийн босго шалгах салааллууд.
- `||` болон `&&` операторын short-circuit үнэлгээ.
- Тэтгэлгийн 0, 50, 70, 100 хувийн буцаах үр дүн.
- `IllegalArgumentException` үүсэх зам.

Нөхцөл бүрийн TRUE болон FALSE салааг ялгаж, тухайн замыг шалгаж буй JUnit тестийн аргын нэрсийг диаграмд тэмдэглэв.

CFG диаграмын файл: **`cfg.png`**

## 7. Дүгнэлт

Энэхүү лабораторийн ажлаар JUnit 5 ашиглан `ScholarshipCalculator` классын бүтцийн тестүүдийг үе шаттай боловсруулж, JaCoCo ашиглан кодын хамрах хүрээг хэмжив. Эхний шатанд line болон branch coverage хангалтгүй байсан боловч нэмэлт салааллын тестүүдээр хоёр үзүүлэлтийг 100%-д хүргэв. Гэсэн хэдий ч 100% branch coverage нь нөхцөл доторх операторын хилийн алдааг заавал илрүүлдэггүйг Section D харуулсан. Тухайлбал, `score > 60` нөхцөл нь 60 онооны үед буруу үр дүн өгч байсныг boundary value test илрүүлсэн. Нөхцөлийг `score >= 60` болгон засварласны дараа бүх 31 тест амжилттай ажиллаж, эцсийн line болон branch coverage 100% болсон. Иймээс coverage-ийн өндөр үзүүлэлтээс гадна хилийн утгууд болон бодит шаардлагад нийцсэн тестийн тохиолдлуудыг боловсруулах нь чухал юм.
